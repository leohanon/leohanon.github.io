# leohanon.github.io

My resume as a website: a timeline of where I've worked, what I did there, and the projects I've built through Guayaba Games LLC.

Live at https://leohanon.github.io

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All the text, dates, logos and screenshots are listed in `src/data.js`. Images live in `public/media/`.

Pushing to `main` builds the site and publishes it with GitHub Pages (`.github/workflows/deploy.yml`).

The UpScrolled screenshots are the real admin UI running against a fake API with made-up tickets.
